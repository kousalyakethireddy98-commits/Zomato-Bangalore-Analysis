# Zomato Bangalore Restaurants Analysis

I analyzed 50,000+ Zomato restaurants in Bangalore using Python.

## What I Did
- Cleaned data using Pandas (fixed rating like 4.1/5 to 4.1, cleaned cost column)
- Found Average Rating is ~3.6
- Found Top Locations: BTM, HSR, Koramangala have most restaurants
- Found Top 10 Highest Rated Restaurants
- Created visualizations using Matplotlib

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Finding
Most restaurants in Bangalore are rated between 3.5 to 4.1
